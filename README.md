# StayEase - Hotel Booking Frontend

A frontend-only hotel booking platform created using HTML, CSS and JavaScript.

## Features

- Hotel search by destination
- Check-in / check-out date fields
- Guest selection
- Hotel cards with pricing, ratings and amenities
- Filters for location, maximum price, rating and amenities
- Room availability display
- Booking form with guest details
- Demo payment-method selection
- Booking confirmation with generated booking ID
- Login modal
- Admin dashboard showing bookings, rooms and reviews
- Responsive layout for desktop, tablet and mobile

## How to run

1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge or Firefox.
3. No server or installation is required.

## Important

This is a frontend demonstration. The payment section does not process real payments.
For a real project, backend/database integration, authentication, real-time availability
and a secure payment gateway would be added.
